# Archive

Candidate files the gold set was first built from (2026-11-18). Kept for provenance
only; `goldset/goldset.csv` is the only answer key and these files are not read
by any code.

- `goldset_candidates_trondheim_bunndyr.csv`: Anders' first candidate list
  (kommune programme, NTNU notes, NVA lookups), imported into `goldset.csv`.
- `goldset_candidates_gbif_baseline.csv`: rows proposed from the GBIF baseline
  (dataset × collector × period × locality), appended to `goldset.csv`.
